# OBSIDIAN-Nikki-Generator
Diary Generator.
Make new sentence by Markov chain from your markdownfile.
# How to Use
1. Click scissor botton.
2. Fill propaty.
- Input file: original file.
- Number of Paragraph: default is 0.
- Output file: output file.
3 Click Submit.
